    1. 创建 notification_panel.js 模块，参考 modal.js 的模式：
       ```javascript
       export class NotificationDrawerManager {
         constructor() {
           this.container = document.getElementById('notification-panel-container');
           this.panel = document.getElementById('notification-panel');
           this.previousBodyOverflow = null;
           this.isOpen = false;
         }
         
         open() { /* 显示面板，锁定滚动 */ }
         close() { /* 隐藏面板，恢复滚动 */ }
         toggle() { /* 切换状态 */ }
         lockBodyScroll() { /* 同时锁定 body 和 html */ }
         unlockBodyScroll() { /* 恢复滚动 */ }
       }
       
       let drawerInstance = null;
       export function getNotificationDrawer() {
         if (!drawerInstance) drawerInstance = new NotificationDrawerManager();
         return drawerInstance;
       }
       ```
    
    2. open() 方法实现：
       - 移除 .hidden，添加 .open 类
       - 设置 aria-hidden="false"
       - 锁定 body 和 html 滚动（style.overflow = 'hidden'）
       - 分发 'notification-drawer:opened' 自定义事件
    
    3. close() 方法实现：
       - 移除 .open 类，添加 .hidden
       - 设置 aria-hidden="true"
       - 恢复滚动
       - 分发 'notification-drawer:closed' 自定义事件
    
    4. 滚动锁定实现（参考 modal.js 的 lockBodyScroll/unlockBodyScroll）：
       - 同时锁定 document.body 和 document.documentElement
       - 保存原始 overflow 值用于恢复
    
    5. 在 bootstrap.js 中导入并初始化（但暂不绑定事件）：
       - import { getNotificationDrawer } from './features/notification_panel.js';
       - 导出 getNotificationDrawer 供其他模块使用
    
    关键约束：
    - 不使用 window 全局变量，使用 ES6 导出
    - 滚动锁定必须同时锁定 body 和 html（防止滚动穿透）
