# Phase 1: 基础面板与核心交互 - Context

**Gathered:** 2026-02-23
**Status:** Ready for planning

<domain>
## Phase Boundary

右侧滑出通知面板，用户可以从首页铃铛入口打开面板、浏览通知列表（未读优先）、滚动加载更多、批量标记已读，并支持完整的关闭机制（外部点击/ESC/关闭按钮）和无障碍访问。

**不包含：** 通知详情展开、Markdown 渲染（Phase 2）

</domain>

<decisions>
## Implementation Decisions

### 面板样式与布局
- **宽度**：响应式 320-400px，根据屏幕宽度自动调整
- **标题栏**：标题 + 全部已读按钮 + 关闭按钮（完整功能）
- **背景遮罩**：无遮罩，面板悬浮在内容上方，点击面板外关闭
- **滚动锁定**：打开面板时锁定 body 滚动（防止滚动穿透）

### 通知项展示
- **显示信息**：标题 + 时间（相对时间）+ 摘要 + 类型图标
- **已读/未读区分**：组合方式
  - 未读：左侧蓝色竖线 + 标题加粗 + 浅色背景
  - 已读：无竖线 + 常规字重 + 无背景
- **摘要长度**：单行截断，超出显示省略号
- **hover 效果**：背景高亮 + 轻微阴影（上浮效果）

### 交互反馈
- **加载更多**：骨架屏（skeleton loading）
- **首次打开**：骨架屏
- **全部已读**：列表刷新动画（所有未读项平滑过渡到已读状态）
- **Badge 更新**：数字渐变动画（从旧值平滑过渡到新值）

### 空状态与边界
- **空状态**：空状态图标 + 文字提示（"暂无通知"）
- **加载失败**：错误提示 + 重试按钮
- **无更多数据**：底部文字提示（"已显示全部通知"）
- **全部已读后**：「全部已读」按钮变为禁用状态

### Claude's Discretion
- 滑出动画时长和缓动函数（建议 200-300ms ease-out）
- 骨架屏具体样式和动画
- 类型图标的具体设计（稀有卡牌/任务状态/系统警告）

</decisions>

<specifics>
## Specific Ideas

- 无遮罩设计类似 macOS 通知中心，保持主内容可见
- hover 效果要有"上浮"感，不是简单的颜色变化
- 全部已读的动画要流畅，让用户感知到状态变化

</specifics>

<deferred>
## Deferred Ideas

- 通知详情展开与 Markdown 渲染 — Phase 2
- 通知筛选功能 — 未来版本
- 多标签页 Badge 同步 — 技术债务，后续优化

</deferred>
