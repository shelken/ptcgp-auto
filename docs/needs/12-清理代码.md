## 需求

### 清理 debug tools

检查 debug tools中目前无用的逻辑，我将把最近使用命令贴出来，你根据命令，反推可能无用的地方，大幅缩减代码。然后将残留在v1中的代码移动到v2过去。

反推时我希望你直接问我哪些是否还要保留。把功能清单列出来，我来抉择。

交互模式中我已知的可以保留的：
`截图并保存`
其他可以不需要，而且可以去掉交互模式了,也就是这个命令`python debug_tool.py`进入的界面的功能。
