# PTCGP 单人对战自动化脚本设计文档

## 概述

在 Mac 上的 BlueStacks Air 模拟器中，通过 ADB + Python 实现 PTCGP（Pokemon TCG Pocket）单人对战的自动刷关脚本。

## 需求

- 自动遍历所有未完成的单人对战任务
- 识别任务状态（Complete/CLEAR vs 数字）
- 自动点击开始对战、等待对局结束、领取奖励
- 不需要操作卡牌（游戏内有自动对战功能）

## 游戏导航层级

```
主界面
  └── 对战（底部第二个图标）
        └── 单人对战
              ├── [特别活动] （可选）
              ├── 初级  → Complete / 10/35
              ├── 中级  → Complete / 数字
              ├── 高级  → Complete / 数字
              └── 精英  → Complete / 数字
                    │
                    └── 某等级内部（如初级）
                          ├── 当前卡包牌组列表
                          └── 扩充组（右上角）
                                ├── A系列
                                └── B系列
                                      └── 各卡包 → CLEAR / 数字
```

## 单次对战流程

1. 点击牌组 → 弹出选牌界面
2. 确认"自动"开启 → 点击"对战"
3. 等待对局结束 → 点击"点击来继续"
4. 领取沙漏奖励 → 继续下一个

## 状态识别策略

| 位置 | 已完成 | 未完成 |
|------|--------|--------|
| 等级入口（初级/中级...） | `Complete` | 数字如 `10/35` |
| 卡包入口 | `CLEAR` | 数字如 `3/5` |
| 对局结束 | 出现「点击来继续」文字 | 无 |

### 识别方案：OCR + 模板匹配混合

1. **OCR 识别文字** - 用 easyocr 识别 Complete、CLEAR、数字
2. **模板匹配** - 用 OpenCV 模板匹配定位按钮位置

## 主循环逻辑

```
1. 启动 → 进入单人对战界面

2. 遍历等级 [初级, 中级, 高级, 精英]:
   ├── 检查状态，跳过 Complete 的等级
   ├── 点击进入该等级
   │
   ├── 遍历当前卡包的牌组:
   │     ├── 点击牌组 → 弹出选牌界面
   │     ├── 点击「对战」
   │     ├── 等待对局结束（检测「点击来继续」）
   │     ├── 点击继续 → 领取奖励
   │     └── 重复直到当前卡包打完
   │
   ├── 点击「扩充组」→ 遍历 A/B 系列:
   │     ├── 跳过 CLEAR 的卡包
   │     ├── 点击未完成卡包
   │     └── 重复上面的牌组遍历流程
   │
   └── 返回单人对战界面

3. 所有等级完成 → 脚本结束
```

## 等待策略

| 场景 | 等待策略 |
|------|----------|
| 对局进行中 | 每 5 秒截图检测「点击来继续」 |
| 页面切换 | 固定等待 1-2 秒 |
| 按钮点击后 | 等待 0.5 秒防止连击 |

## 技术栈

| 库 | 用途 |
|----|------|
| adbutils | Python 封装的 ADB 操作 |
| opencv-python | 模板匹配定位按钮 |
| easyocr | 识别文字状态 |
| Pillow | 图像处理 |
