# Waydroid

基于容器的 Android 方案，专为 Linux 桌面设计，需要 Wayland。

## 关键信息

- **官网**: https://waydro.id
- **GitHub**: https://github.com/waydroid/waydroid
- **Android**: 基于 LineageOS 13

## 与 Redroid 对比

- Waydroid：Linux 桌面集成，单实例
- Redroid：云端/服务器，多实例

## macOS 兼容性

不支持。需要 Linux + Wayland。
